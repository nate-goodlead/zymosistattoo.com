# Zymosis Tattoo

Independent tattoo-artist portfolio and inquiry site for [zymosistattoo.com](https://zymosistattoo.com).

Lisa / Zymosis Tattoo — Haarlem, Netherlands. Instagram [@zymosistattoo](https://www.instagram.com/zymosistattoo/).

## Stack

Next.js 16 App Router, TypeScript, Tailwind CSS 4. Deployed on Vercel. Motion, booking, and backend land in later phases.

## Local development

```bash
cp .env.example .env.local
npm install
npm run dev
```

```bash
npm run lint
npm run typecheck
npm run build
```
